# S.T.A.L.K.E.R. Vita

Portage non officiel de Shadow of Chernobyl sur PS Vita, en développement.

Version du code : **0.0.28**. Le jeu complet n’est pas encore porté. Le parcours couvre une partie du Cordon, de la Décharge, d’Agroprom et de ses souterrains, jusqu’à la planque de Strelok. Cible : 30 FPS, à confirmer selon les zones sur console.

Ce dépôt contient le code et les tests, sans données commerciales. Archives, textures, modèles, musiques et voix doivent provenir de ton propre exemplaire PC.

Le build de vérification utilise des sons muets et des visuels LiveArea de remplacement générés localement. Les VPK de développement avec sons/images du jeu ne sont pas publiés ici. Licences d’origine conservées ; projet non affilié à GSC Game World.

Derniers correctifs : confirmation avant changement de zone, filtrage des collisions et préparation des menus pendant le chargement. La 0.0.28 réutilise le sélecteur de sauvegardes et ne recrée que les textes des emplacements modifiés ; son gain sur Vita reste à confirmer.
