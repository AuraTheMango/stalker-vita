# S.T.A.L.K.E.R. Vita

Portage non officiel de Shadow of Chernobyl sur PS Vita, en développement.

Version du code : **0.0.25**. Le jeu complet n’est pas encore porté. Le parcours couvre une partie du Cordon, de la Décharge et d’Agroprom. Cible : 30 FPS, à confirmer selon les zones sur console.

Ce dépôt contient le code et les tests, sans données commerciales. Archives, textures, modèles, musiques et voix doivent provenir de ton propre exemplaire PC.

- [Compiler](docs/BUILD.md)
- [Contrôles](docs/CONTROLS.md)
- [État actuel](docs/STATUS.md)
- [Reprise du développement](HANDOFF_WSL.md)

Le build de vérification utilise des sons muets et des visuels LiveArea de remplacement générés localement. Les VPK de développement avec sons/images du jeu ne sont pas publiés ici. Licences d’origine conservées ; projet non affilié à GSC Game World.
